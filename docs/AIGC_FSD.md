# FSD AIGC 检测（第三人任务）

本模块在非商业课程/研究用途下，独立使用 FSD 做图像级 AI 生成倾向检测，不改变 SICA/RITA/RiSE。

## 准备

1. 按 FSD 官方仓库说明在独立 Python 环境安装依赖，并检出经核对的固定版本到 `.tools/fsd/`。
2. 复制 `config/aigc.example.json` 为 Git 忽略的 `config/aigc.local.json`，填写 Python 路径、FSD 源码路径及运行选项。
3. FSD 上游在首次调用时自动下载检测权重至用户缓存。使用前需联网；权重约 55 MB，首次下载超时窗口为至少 15 分钟。来源归因默认关闭，开启后还会下载约 233 MB 的归因权重。

## 使用和限制

在“开发与单模型调试”中选择“FSD AI 生成检测”。报告保留 FSD z-score 和阈值；分数不是概率，阈值未经本项目目标图片校准。来源归因不保证正确，且仅对上游支持来源有效。FSD 官方代码许可为 CC BY-NC-SA 4.0，仅限非商业用途并要求相同方式共享。当前接入不代表已经完成本项目数据上的效果验证；首次下载和真实桌面端推理仍需本机验证。
