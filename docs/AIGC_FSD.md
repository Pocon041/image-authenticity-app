# FSD AIGC 检测（第三人任务）

本模块在非商业课程/研究用途下，独立使用 FSD 做图像级 AI 生成倾向检测，不改变 SICA/RITA/RiSE。

## 准备

1. 按 FSD 官方仓库说明在独立 Python 环境安装依赖，并检出经核对的固定版本到 `.tools/fsd/`。
2. 复制 `config/aigc.example.json` 为 Git 忽略的 `config/aigc.local.json`，填写 Python 路径、FSD 源码路径及运行选项。
3. 当前适配器默认将权重放在项目的 `weights/fsd/v1.2.0`，也可设置 `weightsPath`。存在旧用户缓存时先复制缺失文件，不删除旧缓存；文件齐全后可离线推理。首次缺少权重时需联网下载，检测权重约 55 MB，首次下载超时窗口为至少 15 分钟。来源归因默认关闭，开启后还会下载约 233 MB 的归因权重。

## 内存与执行稳定性

官方实现会一次展开整张图的图块；本地真实失败记录中曾单次申请约 7.56 GiB CPU内存。当前由 `backend/aigc/streaming.py` 按行批次提取图块，再调用原约束最小二乘求解器，默认尺寸下每批最多16384个图块；保留float64、原预处理、尺度顺序、权重及阈值。两组数值等价单元检查通过，失败票据实际重测成功且分数与既有成功结果相同。此项验证说明执行与数值保持一致，不是检测准确率评测，也不保证任意系统负载下都能运行。

验证命令：`<配置的Python> -m unittest discover -s backend/aigc -p test_streaming.py`。运行报告的 `extensions.execution` 记录实际设备和分批设置；各模型请求目录中的 `worker.json` 保留退出、超时、取消及有限错误日志。

## 使用和限制

在“开发与单模型调试”中选择“FSD AI 生成检测”。报告保留 FSD z-score 和阈值；分数不是概率，阈值未经本项目目标图片校准。来源归因不保证正确，且仅对上游支持来源有效。FSD 官方代码许可为 CC BY-NC-SA 4.0，仅限非商业用途并要求相同方式共享。已有本机真实桌面运行成功记录；当前接入不代表已经完成本项目数据上的效果验证。
